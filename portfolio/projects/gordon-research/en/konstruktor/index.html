This is a framework — every brief of mine starts with it.
My real briefs are several times longer. First I interview the client: I call, ask again, clarify. Then I put together a specification several pages long in a separate project, where the prompt is built from the models’ own documentation. I run the brief in several systems at once, and the results of one become the input of another. Given a brief like that, the model starts suggesting checks that weren’t in the task.

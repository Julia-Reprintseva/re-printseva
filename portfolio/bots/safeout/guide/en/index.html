How to use SafeOut

Bot: @safeout_dates_bot. SafeOut stores all the information about a date with someone you only know online, and if you don't check in on time — it will automatically message your trusted contacts (who connected via Telegram) with all the saved details. Available in English, Russian, and Turkish (/language).

1
Quick start

Open @safeout_dates_bot, press Start, choose your language, and add at least one trusted contact — /contacts → ➕ Add contact.

The bot will ask for their name, phone number, email, and Telegram username — everything except the name can be skipped with /skip. The username will come in handy for the "Call contact" button during a date. At the end, the bot sends an invitation link that you need to forward to that person. Telegram doesn't allow a bot to message someone who has never started a chat with it, so without clicking the link and pressing Start, the bot physically cannot reach your contact in an emergency.

2
Before the date — /newdate

The bot will ask one by one: the person's name and their app username, a link to their profile, the meeting location, where you might go next, their car details, any other important information, and the time you plan to be home. Anything optional can be skipped with /skip.

Then send everything you have: photos of the person, screenshots of your chats, photos of documents, voice messages. When you're done — tap ✅ Done with files.

Where do these files go. Nowhere extra — when you send a file it stays on Telegram's servers, like any message to the bot, and SafeOut only stores a reference to it. The file becomes accessible only if an alert fires: a trusted contact receives a link to the alert page, and the file loads from Telegram when they open it. Access to the page is based on knowing the link alone, with no password — so if the link reaches the wrong hands, anyone with it can open the files.
3
Safety checklist

The bot shows a checklist: some items it fills in automatically, the rest you check manually. Items marked (!) are required (for example, "first meeting in a public place"). When everything is ready — tap ▶️ All set — start the date.

4
During the date

Right after starting, share your live location with the bot (paperclip → Location → Share live location) — then your contacts will see exactly where you are if an alert fires.

Every 15 minutes the bot sends a short check-in with 3 questions: ✅ All good — the date continues; ⚠️ There's a problem — the bot offers a full checklist, a call to your contact, or continuing under its watch; 🆘 SOS — immediate alert. Check your status manually at any time with /status.

If you don't respond to a check-in — 15 minutes later the bot automatically messages your trusted contacts who are connected in Telegram, with all saved information and a link to the alert page (including the last known location, if you shared it with the bot).

If none of your contacts are reachable — the bot won't let you start the date and will warn you clearly, rather than silently doing nothing when an alert fires.

5
SOS and getting home

The 🆘 SOS button is available in every message during the date and alerts your contacts immediately, without waiting 15 minutes. The 🏠 I'm home, all good button closes the date and sends your contacts a message that everything is fine — all data is saved in your history in case you need it later.

For trusted contacts. If someone sent you an invitation link from SafeOut — follow it and press Start. Without this step the bot can't find you, even if you've already been saved as a contact. From this point on, the bot can message you if your person has a problem on a date, with a link to a page with all the details: who the person is, where they're meeting, the car, photos, last known location (if it was shared with the bot).
Access and pricing. The first 3 dates are free — no sign-up, no card needed. After that — 7 USDT per month via @CryptoBot in Telegram. Tap "Pay" and @CryptoBot opens with the invoice ready. USDT is a dollar-pegged stablecoin (≈ $7). Bank cards and bank transfers are not accepted.

How to repeat this

This bot was built entirely from a script: first I wrote out the full user journey as bot messages and human responses — what you see in the Script tab — and then asked Claude Code to build a real Telegram bot from it. Here's how it works, if you want to do the same for your own idea.

1
Write out the dialogue script

Map out the full user journey as bot messages and human responses — like in the Script section: what the bot asks, which buttons it shows, what happens in each branch — success, error, alert. The more detailed the script, the more accurate the bot: it serves as the technical spec, not just an illustration.

2
Hand the script to Claude

Describe your idea to Claude — in plain text or as an HTML page like this one — and ask it to build a real Telegram bot from it. If you have preferences about the language, database, or hosting — mention them; if not, you can fully trust Claude's choices.

3
Claude Code writes the code

Claude Code writes all the code: command handlers, database schema, background tasks for timers and escalation, and a web page for trusted contacts without Telegram. It registers the bot via @BotFather, and finds and fixes bugs in its own code.

4
Deploys and tests it

Claude Code deploys the bot to cloud hosting from the command line — sets up the database, task queues, and a public URL — and immediately tests it in real Telegram before sharing it with anyone.

The bot's code is open: github.com/Julia-Reprintseva/safeout — feel free to look at it as a reference or fork it for your own idea. Stack: Python, aiogram, PostgreSQL, Redis, Celery, FastAPI, Railway.

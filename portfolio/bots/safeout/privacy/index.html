Какие данные мы собираем

При использовании бота SafeOut сохраняются:

  • Telegram ID, имя и язык пользователя
  • Данные о свидании: имя или ник партнёра, ссылка на профиль, адрес первой встречи, маршрут, номер машины, дополнительная информация
  • Планируемое время возвращения
  • Имена, телефоны и Telegram ID доверенных контактов
  • Файлы (фото, скриншоты, голосовые) — хранятся на серверах Telegram, мы храним только ссылку (file_id)

Цель и основание обработки

Данные используются исключительно для обеспечения безопасности пользователя во время свидания:

  • Отправка тревожных оповещений доверенным контактам при пропуске проверки
  • Формирование страницы тревоги со сводкой информации
  • Выбор языка интерфейса

Правовое основание: добровольное согласие пользователя (ст. 9 Федерального закона № 152-ФЗ «О персональных данных»).

Хранение и защита

Данные хранятся в базе данных на серверах Railway (США). Передача защищена шифрованием. Доступ к данным имеет только оператор.

Данные сессии (информация о свидании, файлы) автоматически теряют актуальность после завершения сессии. Мы не удаляем их автоматически, но не используем после завершения.

Передача третьим лицам

Данные не передаются третьим лицам в коммерческих целях. Доверенные контакты получают ссылку на страницу тревоги только при срабатывании сигнала — это основная функция сервиса, о которой пользователь уведомлён заранее.

Права пользователя

Вы вправе:

  • Запросить удаление всех своих данных — напишите на julia.vl.reprintseva@gmail.com
  • Отозвать согласие — после этого использование бота будет невозможно
  • Получить копию своих данных по запросу

Запросы обрабатываются в течение 30 дней.

Возраст

Сервис предназначен для лиц старше 18 лет. Мы не собираем данные несовершеннолетних намеренно.

Изменения политики

О существенных изменениях сообщаем через бота. Дата последнего обновления указана вверху страницы.

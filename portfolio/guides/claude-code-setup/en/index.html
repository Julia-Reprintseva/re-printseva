Guide · before the workshop

Claude Code: install it before we start

A step-by-step guide for participants. Set-up takes 15–25 minutes. If you only want to watch the demo, you don't need to install anything.

If you are in Russia, you need a VPN. Anthropic, the company behind Claude, does not serve users from Russia. Connect a reliable VPN to Europe, the US or Asia (except China) before you sign up, and check that the country has actually changed — I'll show you how below.

The order of things

  1. Get a subscription — Claude Pro or Max. Claude Code won't start without one.
  2. Turn on the VPN and check your country — both ways, in the browser and in the terminal. This matters more than it sounds.
  3. Install Claude Desktop — the app with the Code tab inside it.
  4. Add the feature-dev plugin — without it you won't be able to follow the demo.
  5. Go through the checklist at the end of the page. Your ticks are saved in the browser.
0 What Claude Code is

It's a tool by Anthropic that lets you talk to an AI assistant while it can see the files on your computer, create new ones and run commands. Unlike the chat on the website, it works right inside your own working environment.

At the workshop we'll be using the Claude Desktop app — the simplest option: download the app, open the Code tab, start working. No terminal, no Node.js, no extensions.

I'll be using my voice at the workshop — it speeds things up a lot when a task needs a detailed description. All of these apps do the same thing, turn speech into text, but they do it differently, and it's worth knowing which is which.

Dictation: text appears wherever your cursor is

This is the kind you'll want at the workshop. Press a hotkey, speak, and the transcript lands straight in Claude's input field, in an email, in a document — anywhere.

Free tier with a cap: 2,000 words a week on desktop, 1,000 on iPhone, unlimited on Android. Pro is $15 a month, or $12 billed annually.

The easiest place to start: install it once and it works across every app. It adapts to how you speak and strips out the filler words.

Spokenly Mac · Windows · Linux · iPhone

Free on local models — no account, no limits, works offline. Pro is $99.99 a year (~$8.33 a month) for cloud models, sync and text clean-up.

The option for people who don't want their voice leaving the machine: the model runs locally. You can also plug in your own OpenAI or Deepgram keys and skip the subscription entirely.

Transcription and voice recorders: not for this workshop

I keep these two for other things. You won't need them at the workshop, but people ask about them often enough that the difference is worth spelling out.

MacWhisper Mac only

There's always a free version. Pro is €64 once, forever, no subscription.

Transcribes existing audio and video files: interviews, call recordings, lectures. Drag a file into the window, get text split by speaker. There is no Windows version.

Whisper Memos iPhone · Apple Watch

$69.99 a year, no free tier.

A recorder for everything that happens away from your desk: talk into your phone or straight into your watch, and the transcript plus a short summary arrives by email. Nothing to do with your computer.

B Checking your country 02

Do this before installing and before every Claude Code session. If the VPN drops or switches to an unsupported country, Claude simply stops replying.

Why both ways

Your browser may reach the internet through a proxy and show the "right" country, while the apps themselves — Claude Desktop, Claude Code — go out directly and see your real one. The terminal check shows you what Claude will see.

This is the only place in the guide where you'll need a terminal, and only if you're in a country where Claude doesn't work.

B.01

In the browser

Open whoer.net and find the "Country" line. If it says Russia, turn on the VPN and reload the page. It should show something like the Netherlands, Germany or the US.

B.02

In the terminal

Required, even if the browser showed the right country

  1. Open Terminal: press ⌘ + Space, type Terminal and hit Enter.
  2. Copy the command below, paste it into Terminal (⌘ + V) and hit Enter.
Terminal · macOS
curl ipinfo.io/country

You should get a two-letter country code back: NL (Netherlands), DE (Germany), US, FR (France) and so on.

If you get RU, the VPN isn't working at the system level. Turn it on, pick the mode that routes all traffic through the VPN (usually called "System-wide" or "Tunnel all traffic"), and check again.

If the country on whoer.net and the one from curl disagree, trust curl — that's the one Claude will see.

  1. Open PowerShell: press Win + X and choose Terminal (Windows 11) or Windows PowerShell (Windows 10).
  2. Copy the command below, right-click into the terminal window to paste it, and hit Enter.
PowerShell · Windows
curl.exe ipinfo.io/country
Why curl.exe and not curl

In PowerShell, curl is an alias for a different command (Invoke-WebRequest) that behaves differently. The real curl is called curl.exe and ships with Windows 10 and 11.

You should get a two-letter country code back: NL, DE, US, FR and so on.

If you get RU, the VPN isn't working at the system level. Switch on the mode that routes all traffic through the VPN ("System-wide", "Tunnel all traffic") and check again.

If the country on whoer.net and the one from curl.exe disagree, trust curl.exe.

C Installing Claude Desktop

The simplest route. No Node.js, no npm, no command line, no extensions — no technical dependencies at all, except one program called Git for Windows, and only for Windows users.

  1. Download

    Open claude.com/download and get the macOS build. It's a .dmg file.

  2. Install

    • Open the downloaded .dmg.
    • Drag the Claude icon into Applications.
    • Launch Claude from Launchpad.
    • If macOS warns you that the app was downloaded from the internet, click Open.

  3. Sign in

    In the app window, sign in to your Claude account — the one with the Pro or Max subscription on it.

  4. Open the Code tab

    At the top left of the window there are three tabs: Chat, Cowork, Code. Click Code, then New session in the sidebar.

    That's it — this is Claude Code with a graphical interface.

  1. Download Claude Desktop

    Open claude.com/download and get the Windows build. It's an .exe file.

    If you're on an ARM-based Windows machine (a Snapdragon laptop, for instance), pick the ARM64 build on the download page.

  2. Install Claude Desktop

    • Run the downloaded .exe.
    • Go through the installer with the default settings.
    • Launch Claude from the Start menu.
    • If Windows Defender SmartScreen warns you, click More info → Run anyway.

  3. Install Git for Windows

    The first time you open the Code tab, Claude may ask for Git for Windows — a separate program for tracking file versions that Claude Code uses under the hood.

    • Open git-scm.com/downloads/win.
    • Download the .exe (Standalone Installer, 64-bit).
    • Run it and click Next at every step — the defaults are fine.
    • Restart Claude Desktop.

    This is not Node.js: Git is a completely different program. You install it once and forget about it.

  4. Sign in

    In the app window, sign in to your Claude account — the one with the Pro or Max subscription on it.

  5. Open the Code tab

    At the top left of the window there are three tabs: Chat, Cowork, Code. Click Code, then New session in the sidebar.

    That's it — this is Claude Code with a graphical interface.

D The feature-dev plugin 04

At the workshop we use Feature Dev, an official plugin by Anthropic. It's a packaged workflow that walks Claude through seven phases: clarifying questions, architecture, implementation, self-review of the code, summary. Without it you won't be able to reproduce the demo.

In the Claude Desktop app, plugins are installed through a visual directory rather than the /plugin command.

  1. Open the plugin menu

    In a Code session, at the bottom left, to the left of the message box, there's a + button. Click it and a menu appears: Slash commands, Connectors, Plugins.

    Hover over Plugins and a submenu opens with two items: Manage plugins and + Add plugin. Choose + Add plugin.

  2. Find Feature dev in the directory

    The Directory window opens with a list of plugins.

    • In the left column, pick the Plugins section — Skills is open by default.
    • Type Feature dev into the search box at the top.
    • In the filter below the search box, pick the Anthropic & Partners tab (next to "Code").
    • In the sub-categories that appear, pick Anthropic.
    • A Feature dev card by Anthropic shows up, described as "Comprehensive feature development workflow…".

  3. Install it

    There's a + button on the right of the plugin card. Click it and the plugin installs. If you're asked about scope, User scope is the right choice: the plugin will work across all your projects.

  4. Check that it's there

    Click + to the left of the message box again → Plugins → Manage plugins: feature-dev should be in the list. You can also type /feature-dev into the message box — a command suggestion should appear.

What the plugin does

You start it with /feature-dev (or /feature-dev:feature-dev if several commands share the name). From then on Claude runs the task for you:

  • asks its own clarifying questions about your idea;
  • proposes an architecture before writing any code;
  • reviews the finished code through specialised sub-agents;
  • sums up what it did.

You'll see all of it in action at the workshop.

E Commands worth knowing 06

Mostly you just write: type the task, press Enter. Or press your Wispr Flow / Spokenly hotkey and dictate it. Everything else is slash commands.

CommandWhat it does
/helpThe full list of commands
/clearClear the conversation and start fresh
/permissionsSet what Claude may do without asking
/memoryLong-term memory: "how to work with me"
/initCreate CLAUDE.md — a briefing for the project
/skillsThe list of available skills
Worth knowing at the start

Claude asks permission before touching files rather often — that's normal, click Yes. When you get tired of confirming, set up /permissions.

The more detail in the task, the better the result: what you want, why, and what the constraints are.

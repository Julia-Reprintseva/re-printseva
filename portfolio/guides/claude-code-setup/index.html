Claude Code: инструкция по установке

Пошаговое руководство. Установка занимает 15–25 минут — от подписки до первого рабочего запроса.

Если вы из России — нужен VPN. Anthropic (компания, которая делает Claude) не обслуживает пользователей из России. Подключите надёжный VPN к Европе, США или Азии (кроме Китая) до регистрации и проверьте, что страна сменилась, — ниже показываю как.

Порядок действий

  1. Оформите подписку Claude Pro или Max — без неё Claude Code не запустится.
  2. Включите VPN и проверьте страну — двумя способами, браузером и через терминал. Это важнее, чем кажется.
  3. Установите Claude Desktop — приложение, внутри которого есть вкладка Code.
  4. Поставьте плагин feature-dev — с ним Claude работает по регламенту, а не наугад.
  5. Пройдите чек-лист в конце страницы — отметки сохранятся в браузере.
0 Что такое Claude Code

Это инструмент от Anthropic, который позволяет общаться с ИИ-ассистентом так, чтобы он видел ваши файлы на компьютере, создавал новые и запускал команды. В отличие от чата на сайте, он работает прямо в вашей рабочей среде.

Ставим Claude Code через приложение Claude Desktop — это самый простой вариант: скачали приложение, открыли вкладку Code и работаете. Без терминала, Node.js и расширений.

A.03

Голосовой ввод

Необязательно · но заметно ускоряет работу

Я пользуюсь голосом — это сильно ускоряет общение с Claude, когда задачу нужно описать подробно. Все эти программы делают одно и то же — превращают речь в текст, — но по-разному, и путать их не стоит.

Диктовка: текст появляется там, где курсор

Это то, что пригодится в работе с Claude. Нажимаете горячую клавишу, говорите — расшифровка вставляется прямо в поле ввода Claude, в письмо, в документ, куда угодно.

Wispr Flow Mac · Windows · iPhone · Android

Бесплатный тариф с лимитом: 2000 слов в неделю на компьютере, 1000 на iPhone, без лимита на Android. Pro — $15 в месяц, $12 при оплате за год.

Самый простой старт: ставится и работает во всех программах сразу. Подстраивается под манеру речи, сам убирает «эээ» и слова-паразиты.

Spokenly Mac · Windows · Linux · iPhone

Бесплатно на локальных моделях — без аккаунта, без лимитов, работает офлайн. Pro — $99,99 в год (~$8,33 в месяц) за облачные модели, синхронизацию и подчистку текста.

Вариант для тех, кому важно, чтобы голос не уходил в чужое облако: модель работает прямо на вашем компьютере. Можно подключить и свои ключи OpenAI или Deepgram — тогда подписка не нужна.

Расшифровка и диктофон: это уже другое

Эти две программы я держу для другого — для работы с Claude они не нужны, но про них часто спрашивают, поэтому объясню разницу.

MacWhisper Только Mac

Бесплатная версия есть всегда. Pro — €64 один раз и навсегда, без подписки.

Расшифровывает готовые аудио- и видеофайлы: интервью, записи созвонов, лекции. Файл перетаскиваете в окно — получаете текст с разбивкой по говорящим. Для Windows не существует.

Whisper Memos iPhone · Apple Watch

$69,99 в год, бесплатного тарифа нет.

Диктофон для того, что происходит не за столом: наговорили на ходу или прямо с часов — расшифровка вместе с кратким пересказом приходит на почту. К компьютеру отношения не имеет.

Коротко

Если нужен один инструмент и без раздумий — берите Wispr Flow: он есть на всех устройствах и его бесплатного тарифа хватит, чтобы попробовать. Если принципиально, чтобы запись никуда не отправлялась, — Spokenly на локальной модели, бесплатно.

Цены проверены в сентябре 2026 года — они меняются, так что перед покупкой посмотрите на сайте.

B Проверка страны 02

Сделайте это до установки и перед каждым запуском Claude Code. Если VPN отключится или переключится в неподдерживаемую страну, Claude просто перестанет отвечать.

Почему двумя способами

Браузер может ходить в интернет через прокси и показать «правильную» страну, тогда как сами приложения — Claude Desktop, Claude Code — идут напрямую и видят вашу настоящую страну. Проверка через терминал показывает то, что увидит Claude.

Это единственное место в инструкции, где понадобится терминал, — и только если вы из страны, где Claude не работает.

B.01

В браузере

Откройте whoer.net и найдите строку «Страна». Если там Россия — включите VPN и обновите страницу. Должно отображаться, например, Нидерланды, Германия, США.

B.02

В терминале

Обязательно, даже если браузер показал правильную страну

  1. Откройте Terminal: нажмите ⌘ + Пробел, наберите Terminal и нажмите Enter.
  2. Скопируйте команду ниже, вставьте в Terminal (⌘ + V) и нажмите Enter.
Terminal · macOS
curl ipinfo.io/country

В ответ должна прийти двухбуквенная страна: NL (Нидерланды), DE (Германия), US (США), FR (Франция) и т. п.

Если пришло RU — VPN не работает на уровне системы. Включите его, выберите режим, при котором весь трафик идёт через VPN (обычно называется «System-wide» или «Tunnel all traffic»), и повторите проверку.

Если страна на whoer.net и страна из curl не совпадают — ориентируйтесь на curl: именно её увидит Claude.

  1. Откройте PowerShell: нажмите Win + X, выберите Terminal (Windows 11) или Windows PowerShell (Windows 10).
  2. Скопируйте команду ниже, вставьте правым кликом в окно терминала и нажмите Enter.
PowerShell · Windows
curl.exe ipinfo.io/country
Почему curl.exe, а не curl

В PowerShell слово curl — сокращение для другой команды (Invoke-WebRequest), которая ведёт себя иначе. Настоящий curl называется curl.exe и встроен в Windows 10 и 11.

В ответ должна прийти двухбуквенная страна: NL, DE, US, FR и т. п.

Если пришло RU — VPN не работает на уровне системы. Включите режим, при котором весь трафик идёт через VPN («System-wide», «Tunnel all traffic»), и повторите проверку.

Если страна на whoer.net и страна из curl.exe не совпадают — ориентируйтесь на curl.exe.

C Установка Claude Desktop

Самый простой путь. Не требует Node.js, npm, командной строки и расширений — никаких технических зависимостей, кроме одной программы Git for Windows, и то только у пользователей Windows.

  1. Скачать

    Откройте claude.com/download и скачайте версию для macOS. Это файл .dmg.

  2. Установить

    • Откройте скачанный .dmg.
    • Перетащите иконку Claude в папку Программы.
    • Запустите Claude из Launchpad.
    • Если macOS предупредит, что приложение скачано из интернета, — нажмите Открыть.

  3. Войти в аккаунт

    В окне приложения войдите в свой аккаунт Claude — тот, на котором оформлена подписка Pro или Max.

  4. Открыть вкладку Code

    В верхней части окна слева три вкладки: Chat, Cowork, Code. Нажмите Code, затем New session в боковой панели.

    Готово — это и есть Claude Code в графическом виде.

  1. Скачать Claude Desktop

    Откройте claude.com/download и скачайте версию для Windows. Это файл .exe.

    Если у вас Windows на ARM-процессоре (например, ноутбуки на Snapdragon) — выберите на странице скачивания версию ARM64.

  2. Установить Claude Desktop

    • Запустите скачанный .exe.
    • Пройдите установщик с настройками по умолчанию.
    • Запустите Claude через меню «Пуск».
    • Если Windows Defender SmartScreen предупредит — нажмите Подробнее → Выполнить в любом случае.

  3. Установить Git for Windows

    При первом открытии вкладки Code Claude может запросить Git for Windows — это отдельная программа для отслеживания версий файлов, Claude Code использует её внутри.

    • Откройте git-scm.com/downloads/win.
    • Скачайте .exe (Standalone Installer 64-bit).
    • Запустите и жмите Next на каждом шаге — настройки по умолчанию подходят.
    • Перезапустите Claude Desktop.

    Это не Node.js: Git — совсем другая программа. Ставится один раз и забывается.

  4. Войти в аккаунт

    В окне приложения войдите в свой аккаунт Claude — тот, на котором оформлена подписка Pro или Max.

  5. Открыть вкладку Code

    В верхней части окна слева три вкладки: Chat, Cowork, Code. Нажмите Code, затем New session в боковой панели.

    Готово — это и есть Claude Code в графическом виде.

D Плагин feature-dev 04

Я работаю через официальный плагин Feature Dev от Anthropic. Это упакованный регламент, который ведёт Claude по семи фазам: уточняющие вопросы, архитектура, реализация, само-проверка кода, итог. Без него Claude начинает писать код сразу, не задавая вопросов.

В приложении Claude Desktop плагины ставятся через визуальный каталог, а не командой /plugin.

  1. Откройте меню плагинов

    В окне сессии Code слева от поля ввода, в левом нижнем углу, есть кнопка +. Нажмите её — появится меню: Slash commands, Connectors, Plugins.

    Наведите курсор на Plugins — откроется подменю с двумя пунктами: Manage plugins и + Add plugin. Выберите + Add plugin.

  2. Найдите Feature dev в каталоге

    Откроется окно Directory со списком плагинов.

    • В левой колонке выберите раздел Plugins — по умолчанию открыт раздел Skills.
    • В строке поиска вверху введите Feature dev.
    • В фильтре под строкой поиска выберите вкладку Anthropic & Partners (рядом с «Code»).
    • В появившихся подкаталогах выберите Anthropic.
    • В списке появится карточка Feature dev от автора Anthropic с описанием «Comprehensive feature development workflow…».

  3. Установите плагин

    В карточке плагина справа есть кнопка +. Нажмите её — плагин установится. Если спросят про область действия, подойдёт User scope: плагин будет работать во всех проектах.

  4. Проверьте, что плагин появился

    Снова нажмите + слева от поля ввода → Plugins → Manage plugins: в списке установленных должен быть feature-dev. Ещё можно набрать в поле ввода /feature-dev — должна появиться подсказка с командой.

Что делает плагин

Запускается командой /feature-dev (или /feature-dev:feature-dev, если найдётся несколько одноимённых). После запуска Claude переходит в режим ведения задачи:

  • сам задаёт уточняющие вопросы по вашей идее;
  • предлагает архитектуру до того, как начать писать код;
  • делает само-проверку готового кода через специализированных под-агентов;
  • подводит итог сделанного.

Дальше — просто попробуйте: опишите идею и посмотрите, как он задаёт вопросы.

E Команды, которые пригодятся 06

Основной способ работы — обычный текст: пишете задачу и жмёте Enter. Или нажимаете горячую клавишу Wispr Flow либо Spokenly и диктуете. Всё остальное — слэш-команды.

КомандаЧто делает
/helpПолный список команд
/clearОчистить разговор, начать новый
/permissionsНастроить, что можно делать без вопроса
/memoryДолгосрочная память «как со мной работать»
/initСоздать CLAUDE.md — памятку для проекта
/skillsСписок доступных скиллов
Что важно знать на старте

Claude часто спрашивает разрешение перед действиями с файлами — это нормально, жмите Yes. Когда устанете подтверждать, настройте /permissions.

Чем подробнее задача, тем лучше результат: что хотите, зачем, какие ограничения.
